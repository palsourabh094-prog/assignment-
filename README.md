📘 Project Overview

The Cafeteria / Canteen Order Manager is a simple yet efficient Python-based console application designed to help automate and manage food orders in a canteen or cafeteria environment.

It provides a menu-driven dashboard where users can browse the menu, add items to a cart, view their order summary, apply discount coupons, and generate a total bill — all through an interactive terminal interface.

This project demonstrates strong skills in Python programming, data handling, loops, conditionals, and user interaction design.

🎯 Objectives

To create an interactive dashboard for managing cafeteria orders.

To implement menu and cart functionalities for a smoother order experience.

To simulate a real-world canteen billing system with discounts and total calculation.

To enhance understanding of data structures (like dictionaries) and control flow in Python.

⚙️ Features

✅ Display a full food & beverage menu with item names and prices.
✅ Add items to cart with quantity input.
✅ View cart and total price dynamically.
✅ Remove items or clear entire cart easily.
✅ Apply discount coupons (DIS10 or DIS20) to get offers.
✅ Automatically shows most selling items.
✅ User-friendly dashboard design for smooth navigation.
